Subject: Getting all photos out of a project at once

From: [person-1] <[email]>
To: [email]

Hi, we finished the drainage survey last week and the client wants all the photos. There are about 1,400 photos across 3 forms. Downloading them one by one from each record is not possible for us. Is there a way to export all photos from a project in one go? Our project manager [person-2] ([email], [phone]) asked me to sort this out before Friday.

From: Support
To: [person-1]

Hello [person-1], yes. In the web app go to Project, then Exports, then choose Photo bundle. It makes a zip file with one folder per form and the photos named after the record id and the field short name. For 1,400 photos the bundle takes a few minutes to prepare; you get an email with a download link when it is ready. The link works for 7 days. If you filter by form or date before you start, the bundle only includes those records. Let me know if that works.

From: [person-1]
To: Support

That worked, thanks. One more thing: the link you sent earlier, [url] opened in the browser but asked for a sign-in. Is that expected? Also, is there a size limit on the bundle? Our next project will have around 10,000 photos.

From: Support
To: [person-1]

The link opens for the person who requested the bundle, so a sign-in is expected if the browser session had expired. The bundle limit is 20 GB per request. Above that, filter by form or date range and make more than one bundle. The limit and the 7-day link are the same for all plans.

From: [person-1]

From: Support
