# Create your first project

A project holds forms, records and the people who work on them.

## Create a project

1. In the web app, open Projects and choose New project.
2. Give it a name and a short code. The code appears in file names of exports.
3. Pick a coordinate reference system. The default is WGS 84.

## Add a form

Open the project, choose Forms, then New form. Start from a blank form or a template. See Building forms for the details.

## Invite people

Open Members and add people by email. Each person gets a role. See Users and roles.
