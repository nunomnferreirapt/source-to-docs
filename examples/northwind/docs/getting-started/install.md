# Install the app

Northwind Field Logger runs on Android 10 or later, iOS 15 or later, and in any current browser.

## Mobile

1. Open the app store on your device and search for Northwind Field Logger.
2. Install and open the app.
3. Sign in with the account your project admin created for you.

## Web

Go to the web address your organization uses and sign in. The web app is read-only for form filling but has the full project, export and admin features.

## First sign-in

On first sign-in the app downloads the projects you have access to. This can take a minute on a slow connection. You can start working as soon as the project list appears.
