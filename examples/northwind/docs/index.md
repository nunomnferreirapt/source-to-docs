# Northwind Field Logger documentation

Northwind Field Logger is a mobile and web app for collecting field data: forms, photos, GPS positions and measurements, with offline sync to a shared project.

## Sections

- Getting started: install the app, create a project, add your first form.
- Forms: build forms, add validation rules, reuse templates.
- Sync: how offline sync works and how conflicts are resolved.
- Exports: get your data out as CSV or GeoJSON.
- Admin: users, roles and project settings.
